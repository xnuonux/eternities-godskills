# Frozen single-assisted browser lifecycle exercise

Freeze task, exact skill/reference snapshots and check.mjs before dispatch.
GPT Luna max, non-forked, native host instructions present. One assisted sample;
no raw baseline, rendered scene, real browser or GPU measurement. Candidate may
read task and the two snapshots only. Parent inspects the generated module for
scope before executing it with the declared fake adapter.

The executable checker covers these independently defined contract behaviors:
inert construction; duplicate start; bounded frame deltas; owned stop/repeated
stop; stale callback; late owned lease; borrowed lease; restart generation race;
current versus obsolete rejection; and resume clock reset. Each expectation is
derived from task.md, not candidate implementation. Preserve failures and candidate
bytes. Passing proves this simplified controller contract only, not a universal
benefit of the skill or real engine resource cleanup.
