# Bounded MiMo consumer exercise

Decision: check whether the revised Daedalus test-design guidance is usable in a small fresh test-writing task without harming contract conformance. This is a one-task smoke comparison, not evidence of general superiority or a domain benchmark.

Freeze the final candidate method and fixture manifest before dispatch. Give two fresh ephemeral MiMo Codex CLI contexts the identical consumer task, model mimo-v2.6-pro, medium reasoning setting, tools, no project-document loading, and common stopping instructions. Exactly one receives the Daedalus entrypoint plus new test-design reference as method.md. Assign condition labels using a random coin before dispatch; launch both without inspecting either output first. This is one randomized pair, not a replicated counterbalanced study.

The baseline is same-host without the explicit Godskills method, not an assertion that all host instructions or safeguards are absent. No consumer receives implementation sources, variant descriptions, the evaluator, other consumer output, project history, or Keel. The parent checks available call records for unintended reads. Instruction-level isolation is not an OS-level confidentiality guarantee.

Each consumer writes tests.mjs using Node built-ins. No target is available during authoring; a syntax check is permitted. The parent executes each returned suite unchanged against the reference and eight variants. A reference failure invalidates the suite. Nonzero exits are only candidates until inspected for a contract assertion or legitimate exception; missing imports, timeouts, signals, and infrastructure errors never count as caught semantic bugs. Invalid or failed runs are preserved without selective retries.

Score reference conformance and individually reviewed variant detections out of eight; report misses and invalid assumptions. Preserve tests, raw evaluator results, final messages, available token/cache usage, and observed duration. Actual monetary charges and provider-internal randomness are unknown unless supplied. Fixed task edge cases may make this exercise easy and ceiling-limited. A tie supports only that no difference was observed here. The independently authored evaluator uses the same model provider as consumers; the parent verifies its executable behavior and final failure classifications.

The source-family author's separate exercise is not used for this comparison. No result upgrades the entire pack beyond its existing instruction-reviewed status.
