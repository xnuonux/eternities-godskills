# Candidate: measured workflow-overhead review

This is fresh portable conditional guidance derived from the retained r0249 mechanism, not source prose.

**Owner:** `eternities-forge`, as an optional review step in its route-selection and claim-tracking loop. No new top-level skill is justified.

**When to apply:** use only when a selected skill, delegated workflow, or multi-skill chain may add material context, tool, process, or repeated-run overhead, or when the user asks whether that overhead is worthwhile. Skip for a small one-shot edit already covered by one narrow process.

**Preconditions:** identify the trigger path, loaded entrypoints and references, tools or commands, repeated-run pattern, target artifact, and available baseline. State whether token counts are measured or qualitative. Preserve safety, approval, freshness, and validation requirements while reviewing cost.

**Method:** compare a baseline run with a skill-enabled run under the same prompt and source material when practical. Record activated skills, loaded files, turns, command and tool output, validation results, and repeated-output compounding. Classify each cost as useful, duplicative, stale, host-specific, or unresolved. Prefer the smallest sufficient composition.

**Outputs:** a short overhead receipt containing the baseline and candidate identifiers, measured or estimated overhead, observed output value, evidence limits, retained safety boundaries, and one recommendation: keep, trim, move detail to references, split, merge, compose through an orchestrator, isolate in an adapter, or defer.

**Stop criteria:** stop when the recommendation is supported by bounded evidence and the acceptance output is unchanged or explicitly re-scoped. Stop and defer when no comparable baseline exists, exact token counts are unavailable and estimates would drive a consequential change, safety would be weakened to save context, or the proposed change exceeds the owning route’s authority. Never claim measured savings from an unmeasured estimate.
