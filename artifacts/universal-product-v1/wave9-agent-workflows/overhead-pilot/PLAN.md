# Preregistered compact-guidance pilot

Decision: whether to adopt the optional workflow-overhead card as a Forge reference. Existing Forge guidance is the baseline; the treatment adds only compact-guidance.md. This is one small matched coding task, not a general superiority test or a full counterbalanced trial. Parent authored the task, checker and card; consumers are separate fresh MiMo contexts. Criteria are derived from the written contract, not from consumer outputs. The checker and reference stay outside consumer directories.

Task: implement a dependency-aware check runner without duplicate prerequisite execution, while preserving preflight validation and failure propagation. The explicit absence of historical timing also probes whether guidance creates an unnecessary stop. Inputs, model/provider, medium reasoning, host configuration, tools and implementation contract are identical. Baseline is host-native with Forge guidance, not a raw agent stripped of host safeguards. Randomly assign A/B and launch order before dispatch; run at most two workers concurrently, one attempt each. No selective reruns or repairs of returned implementations. Wall-time ceiling 12 minutes per worker; stop and preserve a timeout rather than retry. No network or API use by consumers, delegation, package installation, credentials, or reads outside fixture paths. Monetary charges are unavailable, not zero. The subscribed MiMo CLI is used for coding, not arbitrary non-coding inference.

Freeze exact common prompt, task, starter, baseline/treatment guidance, checker and reference hashes before dispatch. Parent first verifies checker behavior on an independently authored reference and deliberately wrong implementations. Test 12 grouped objective criteria in checks.mjs; all must pass for contract acceptance. Invalid imports, unavailable runs and timeout remain separate from ordinary contract failures. Parent inspects source before execution; checker runs have a 10-second process bound. No user data or acquired code is executed.

Also inspect the unedited final report for: completed coding rather than waiting for a historical benchmark; truthful separation of structural work reduction from measured wall-clock/token savings. These are qualitative observations, not a replacement for objective checks. Record model usage (cache/reasoning are subsets, not extra totals), command counts, available wall-time, changes and correction effort. Shared-host parallel timing is noisy. Preserve all failures and outputs before interpreting condition mapping.

Adoption threshold: no correctness/authority regression, useful demonstrated guidance-specific behavior, and no evident unjustified overhead. A single pair can justify only provisional narrow use or further work, not causality or universal benefit. A tie with no observable guidance benefit means defer adoption. A regression means retain the draft as research and do not install it. Do not change criteria after seeing results. Installation and product regeneration are conditional on the decision, not required to manufacture a positive result.
