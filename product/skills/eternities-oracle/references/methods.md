# Oracle method cards

## Local path

List the exact files or records in scope, revision or date, locator, and claims to settle. Inspect implementation reality before summaries. Use bounded excerpts and preserve contradictory evidence. A local result is current only within its observed revision.

## Authoritative path

Declare the freshness cutoff and source standard. For each current claim, record publisher, URL or document identity, revision or publication date, retrieval date, bounded supporting region, and refresh condition. If live retrieval is unavailable, keep the claim deferred.

## Hybrid reconciliation

Build local and authoritative ledgers separately. Match claims by identity, scope, version, and time; classify agreement, local drift, external drift, conflict, and missing coverage. Choose an authority basis for any conclusion and state what evidence would reverse it.

## Negative and comparative work

Before searching, set the retrieval floor, independent routes, corpus boundary, baseline, matched conditions, and stop rule. The strongest bounded negative conclusion is not-yet-refuted or inconclusive, never proof of absence, novelty, or universal coverage.
