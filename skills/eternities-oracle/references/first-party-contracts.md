# Bounded prior-art falsification contract

Declare the comparison claim, retrieval floor, independent search routes, corpus boundary, and stop condition before searching.

- a positive overlap requires an exact retrieved record and bounded locator;
- a negative result requires the retrieval floor and a final corpus-wide overlap review;
- the strongest bounded negative disposition is `not-yet-refuted`;
- missing exact evidence, insufficient retrieval, or an incomplete corpus remains `inconclusive`;
- this route never converts absence of found evidence into proof of novelty.

The executable reference is `src/lunari-first-party-contracts.mjs`. It validates conclusion discipline, not search completeness.
