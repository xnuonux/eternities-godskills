# Falsification and criterion-calibration contract

Express the crux as falsifiable predictions and name the observation that would reject each one. Prefer the cheapest real experiment that discriminates between the live alternatives. Independent observation outranks builder or agent self-report.

An internal-state or mechanism claim is calibrated only when independently observed criterion evidence includes the intervention, a matched control, and prespecified false-positive or error accounting. Without all four elements, return `inconclusive`. A surviving hypothesis remains survived or supported within scope, never universally validated.

The executable reference is `src/lunari-first-party-contracts.mjs`. It validates evidence structure, not scientific truth or generalizability.
