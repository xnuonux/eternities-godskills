# Corpus reconciliation and tiered synthesis

## Scope

Reconcile registered historical corpus records, subsequent GitHub quarry waves,
and September intakes. This is a finite registered-input inventory, not a claim
to possess every AI skill online. Discovery repositories are not skill bodies.
Preserve all originals, aliases, source locations, licenses and prior judgments.

## Compute ownership

- Scripts enumerate inputs, hash snapshots, join identities and group declared
  exact body hashes. They report conflicts rather than choosing a winner.
- Jev handles bounded semantic classification and candidate overlap judgments
  only on eligible public excerpts. Existing matching judgments are reused.
- Luna inspects exact sources for uncertain or consequential groups and drafts
  bounded synthesis with differences, exclusions and observable test criteria.
- The coordinating agent owns architecture, coverage, review and integration.

The shared Jev helper owns admission/accounting. Respect its daily ceiling,
pending-call counter and refusal; do not switch endpoints to evade a stop.
Stable request and snapshot identities prevent duplicate paid submissions.
No whole transcripts, private memory or credentials enter provider batches.

## Ordered gates

1. Inventory every supported source-bearing input and list exclusions. Count
   records, identities, declared bodies and conflicts separately. Hash all input
   files. Unknown raw hashes are not replaced with normalized content digests.
2. Group exact declared body hashes without deleting aliases. This compares
   ledger claims; current source-byte verification is a separate operation.
3. Join previous labels only with their exact source/body bindings. Preserve
   conflicting labels and unknowns. No prior promotion status is inherited by
   an entire duplicate group.
4. Propose semantic candidates using metadata blocking instead of quadratic
   all-pairs provider calls. Every request records the selection method and
   excerpt boundary. Similarity is not functional equivalence.
5. For Jev abstentions, use Luna source review or retain unresolved. Do not keep
   resubmitting until a favorable label appears. Pilot performance determines
   whether short descriptions suffice; low-yield pilots require better source
   packets or a different allocation, not blind scaling.
6. Synthesize only selected coherent capability groups with preserved specialist
   constraints and source identities. Compare baseline and candidate behavior.
   Keep output experimental until the existing promotion gates pass.

## Initial pilot

`data/corpus-overlap-pilot-2026-09-20/receipt.json` binds five cross-repository
description pairs. One paid call returned four abstentions and one advisory
equivalence proposal. Provider-reported cost: 63 microUSD. No merge, deletion,
activation, accuracy or full-body equivalence follows from this pilot.
The unresolved groups and proposal are assigned to a bounded Luna source review.

## Completion boundaries

Inventory completion requires reproducible counts and explicit exclusions.
Classification completion requires a disposition for every eligible unique
body, including unknown/deferred, not universally confident labels. Synthesis
completion requires a coverage map from each source family to a disposition;
promotion requires the existing evidence contract. None of these is interchangeable
with whole-product completion or universal superiority.
