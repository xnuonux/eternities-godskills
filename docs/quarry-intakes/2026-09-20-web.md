checks used the saved inventory instead. Existing repositories were untouched.

origin was confirmed, repository-local `core.longpaths` enabled, and the interrupted
checkout restored and verified clean. No global Windows or Git setting changed.

## Atomic Jev classification

499 of the 504 unique bodies were processed; five exceeded the 48,000-byte
specimen bound and remain explicit exclusions. There were 167 sequential calls,
three documents per call at most, six independent yes/no/unknown questions per
document. The pinned model was `jev-1.13.0`. No retries were made. Each call had a
20-second timeout, predispatch reservation, and preserved response. Authentication
or quota errors would stop the batch; none occurred.

Facets: research, plan, build, verify, recover, orchestrate. These are nonexclusive
descriptions of the method's central activities, not permissions or quality scores.

- Reported input tokens: 1,740,010.
- Transport errors: zero.
- Provisional yes/no decisions at confidence >=0.9: 1,716 of 2,994.
- Remaining 1,278 decisions: unknown or below threshold; retained for review.

This is unqualified model enrichment, **not 57% classification accuracy**. There
are no independent truth labels for this batch. Provider confidence is not
calibrated and one source could influence another within a batch; single-document
ablation and adversarial qualification remain required before adoption.

## Usable now: read-only source search

The following command searches registered intakes without loading skill bodies,
executing source code, or calling an API:

```powershell
node scripts/query-cold-intakes.mjs --query "web performance" --facet verify --limit 2
```

Omit `--facet` for ordinary lexical lookup. Filters only accept same-body,
high-confidence provisional positive labels; conflicting labels do not pass.
Unknown labels are not negative evidence. If a filtered query is empty, retry
without the facet or use the existing certified quarry atlas. This is opt-in
discovery, not a replacement for the router or a source safety decision.

The real filtered query above returned web-quality-audit and a React Native TV
review method. A robot-simulation query with the verify filter returned nothing;
unfiltered search did return candidates. Retrieval relevance remains approximate.

Seven new behavioral tests pass: metadata-only output, body deduplication, source-ID
conflict exclusion, same-body facet binding, conflicting-label refusal, and bounded
query validation and malformed duplicate rejection. Full run: 856 tests, 849 passed, five pre-existing failures,
two skipped. The failures remain historical Aegis host-policy, Athena source-hash,
and continuity-source checks. No stale certification was rewritten.

## Route to a finished release

The existing finite v1 completion contract still governs the product. Larger
collection is an input, not its completion condition. Keep public discovery
versioned and separate from the portable shipping pack:

1. Resolve or quarantine the 163 historical identity conflicts already recorded.
2. Qualify atomic labels on independent, stratified specimens; handle long sources
   with verified section boundaries, not silent truncation.
3. Process the remaining discovered frontier in bounded deduplicated batches.
4. Select gaps worth filling, inspect exact methods and notice obligations, and
   synthesize or improve first-party skills with worked examples and failure cases.
5. Measure retrieval, context cost and real agent outcomes against existing/raw
   baselines; do not activate methods merely because labels look plausible.
6. Ship a portable, versioned pack with known limitations, installation/rollback
   checks, and the existing release gates satisfied. New internet discoveries
   become later-version inputs rather than moving v1's finish line indefinitely.
