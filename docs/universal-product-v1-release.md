## Verification

The initial full regression run after product integration passed 918 tests,
with one platform-dependent symlink test skipped. Independent runtime review
then found seven additional defects. Each was reproduced with a failing test,
fixed, and independently rechecked; see [the complete review](universal-runtime-review.md).
The final pre-integration run passed 930 tests, zero failed, one skipped (931 total),
including a real C:/D: cross-volume preflight case and native Windows junction
archive/restore. Four corpus-review accounting tests are included in this total;
they validate metadata accounting, not skill quality.

The clean-room test copies only the product outside the repository, clears PATH,
and invokes its CLI with the Node executable explicitly. No dependencies are
installed and no provider is called. This verifies dependency separation on the
tested Windows host; it is not an observed Linux/macOS installation claim.

Twelve task-query fixtures found the intended skill among the first three
candidates; nonsense and task filters were also checked. These are retrieval
regressions, not general semantic-search accuracy or task-quality measurements.

A fresh Luna max worker read the rewritten API-retry skill and a bounded
implementation contract, without reading the acceptance tests. Its submitted
client passed seven parent-authored tests covering stable idempotency keys,
bounded attempts, deadlines, malformed hints, cancellation, validation and
terminal/transport errors. The real output and report are in
`artifacts/universal-product-v1/exercises/`. This has no matched raw-agent baseline
and establishes no superiority, live-provider behavior or concurrency guarantee.

## Local installation

The authorized Codex installation received all 54 skill directories and a
standalone runtime pack. Seven old junctions were archived intact, without
changing their repository targets. All 56 unrelated installed files matched
their pre-install snapshot. The install receipt and archived junctions are
stored outside the repository under the user's agent configuration directory.

Compact host instructions now identify the pack and optional search command,
preserve task-scoped selection, avoid mandatory slash commands or blanket skill
loading, and keep checkpoint work at meaningful boundaries. The host reloaded
those instructions in the active task. Other tasks may cache their skill catalog;
file installation is not proof that every already-open task has refreshed it.

Local rollback follows the two pack receipts in reverse installation order
(`universal-v1-20260921-r2`, then `universal-v1-20260921`). The second installation
only incorporates final deterministic INDEX formatting and its builder change;
the skill bodies are unchanged. After reverting both normal packs, run
`scripts/migrate-local-godskill-junctions.ps1 -Mode Restore` with the same explicit
skill, legacy-source and archive roots used during migration. Both recovery mechanisms
were tested on temporary fixtures; live rollback was not performed. Previous
global instructions are separately backed up.

Jev pacing stopped the attempted bulk pass. Luna workers use compact judgments;
deterministic code binds source identities and rejects duplicates, stale scope,
invalid mappings and missing coverage. Classification is not source-body review
or incorporation. The older reconciled corpus still includes unresolved identity
conflicts and missing body declarations. These remain explicit research work,
not silently installed instructions or evidence of an ultimate finished corpus.
