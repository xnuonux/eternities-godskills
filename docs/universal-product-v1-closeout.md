running task automatically.

## Next coherent development

Use the checked queue to select exact source bodies for narrowly missing methods,
not to install bulk classifier output. Highest-value follow-up areas include
geospatial/environmental analysis, model-experiment lineage, specialized audio
workflows, and currently thin professional subdomains. Resolve conflicting source
identities before relying on their provenance. Keep existing useful methods small;
add references or specialists only when a real method would otherwise be lost.

Test the next candidate on representative held-out tasks with an ordinary agent
baseline and explicit quality/cost criteria. Keep measured gains, preserve
regressions, and revise or remove procedures that add overhead without benefit.
The installed release is usable now; complete corpus-wide distillation and broad
agent-outcome qualification remain unfinished and are not hidden by this release.
