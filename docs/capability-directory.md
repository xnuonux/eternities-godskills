## evidence labels

- **present**: files and source records exist.
- **contract-tested**: named local checks support specific invariants.
- **agent-tested**: a real agent attempted an identified task under recorded conditions.
- **performance-qualified**: a particular activation improved a matched task
  class under declared quality, regression, and resource gates.

existing `promoted` records can mean deterministic contract promotion, not
performance qualification. this directory assigns no unverified new maturity
level to individual skills.
