# Eternities Godskills Release Three

Release three promotes `eternities-mnemosyne`, the bounded memory and context Godskill.

## certified capability

Mnemosyne chooses one of four routes: continuity recovery, context budgeting, memory-system design, or memory audit. It separates active state, durable judgments, evidence, and raw archive; retrieves the smallest sufficient layer; preserves freshness and contradiction; and stops when the next consumer can proceed without replaying history.

It deliberately bypasses routine turns, status checks, simple factual recall, and fresh self-contained tasks. Actual Codex session or compaction boundaries remain owned by `keel-wake`; source research remains owned by `eternities-oracle`; concrete retrieval regressions remain owned by `systematic-debugging`.
