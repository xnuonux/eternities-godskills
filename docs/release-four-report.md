# Eternities Godskills release four report

## outcome

Release Four adds `eternities-muse`, a bounded Godskill for consequential visual forensics, interface art direction, narrative motion, and deterministic visual acceptance. It is independently written, contract-certified, and deliberately separate from ordinary frontend edits and exact media-production skills.

Muse passed 17 of 17 critical direct, paraphrase, exclusion, and conflict fixtures. Its entrypoint measures 1,294 estimated tokens against the 4,000-token policy ceiling. The declared baseline measured 7,200 tokens and collapsed most work into one unbounded visual-director route.

## critical design decision

Muse is not added to `eternities-engineering`. Release Four creates a separate `eternities-visual` profile whose lock contains only Muse. This keeps the broad engineering prompt unchanged while making visual-system activation independently reversible.

The profile is not activated from the temporary worktree. Activation remains deferred until the reviewed commit is fast-forwarded into canonical `C:\dev\eternities-godskills`.

## route system

| route | owns | yields when |
|---|---|---|
| `visual-forensics` | confidence-labeled identity, tokens, components, layout, accessibility, and reconstruction evidence | direction is settled and local implementation assets are needed |
| `interface-art-direction` | one generative visual law, hierarchy, token and component grammar, responsive and accessibility contracts | exact frontend construction begins |
| `motion-story` | emotional arc, chapter jobs, causal transitions, media beats, reduced motion, and compute tiers | a final image, narration, or subtitle render is requested |
| `visual-acceptance` | deterministic manifests, baselines, diagnostics, state and device coverage, budgets, invariants, and rejection criteria | a concrete implementation regression must be diagnosed |

Mixed missions settle the earliest unresolved route and hand a bounded contract to the next specialist. Muse cannot delegate to itself.
