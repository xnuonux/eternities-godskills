This release refines the existing Atlas skill; it does not add another skill ID or import a source pack.

| Route | Included | Boundary |
| --- | --- | --- |
| Finite Pareto frontier | Original, bounded oracle and separate output verifier, with a portable method reference and discovery terms. | Computes a partition of caller-declared values, not a winner. Source truth, comparability, feasibility evidence, rights, and external owner approval remain unvalidated; consequential recommendations HOLD. The optional checker requires Node 24 or newer. |
| Simulation-artifact handoff | Portable written contract for run context, access/retention, field-level units, stable bytes, authenticated manifest, and receiver checks. | No snapshot adapter, packager, validator, simulation run, scientific/FAIR certification, or rerun proof is bundled. A writer-locked or immutable source and platform-specific safe path access must be established separately; otherwise HOLD. |
