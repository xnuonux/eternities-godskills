# Eternities Godskills Release Three Mnemosyne Implementation Plan

**Goal:** Promote one independently written memory and context Godskill that reconstructs continuity, budgets active context, designs durable memory, and audits retrieval without becoming an always-on tax.

**Architecture:** Eternities Mnemosyne is a bounded categorical router. It separates active task state, durable judgments, raw evidence, and recoverable history; retrieves the smallest sufficient layer; marks freshness and conflict; delegates exact boundary or research work; and terminates with a compact continuity or memory contract. It does not replace `keel-wake`, force recall on routine turns, or install a memory backend.

**Evidence:** Five certified catalog records are used. Permissive sources support independent implementation. PolyForm Noncommercial and AGPL sources remain pattern-only. No source prose, code, runtime, hook, or backend is copied.
