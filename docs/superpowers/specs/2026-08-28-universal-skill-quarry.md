## Purpose

Expand the certified Eternities source quarry with current, high-signal public agent-skill repositories that add mechanisms not represented in the original 4,741-card corpus.

## Outcome

- acquire exact upstream repositories as inert source evidence under `D:\03-ARSENAL\warehouse\hunt\agent-skills-universal-wave-2-2026-08-28`;
- deduplicate candidates against the existing corpus and destination paths;
- record upstream identity, revision, license signal, and acquisition status;
- index skill bodies without installing or executing third-party code;
- select missing capability mechanisms for separate sovereign refinery waves;
- preserve all candidates cold until a promotion receipt explicitly passes.

## Success conditions

1. Every accepted repository has a clean shallow checkout, canonical GitHub origin, and exact HEAD digest.
2. Existing corpus sources and duplicate upstream identities are not reacquired.
3. Unknown or restrictive licenses remain pattern-only.
4. No third-party setup, hooks, binaries, skills, or runtime code are executed.
5. The current Godskills router remains unchanged during acquisition.
6. A dated receipt separates acquired, existing, rejected, deferred, and failed sources.
7. A cold-index delta identifies skill bodies and capability gaps without loading them into ordinary agent context.

## Exclusions

- this wave does not claim to contain every GitHub repository;
- acquisition is not semantic promotion;
- repository popularity is not evidence of capability quality;
- no Luna, Codex, Claude, or global host adapter is activated;
- live external actions described by a source remain unauthorized.
