# Compiler Generalization v2 Design

## Purpose

Permit ordinary-language missions to reach a small compatible Godskill composition without requiring an untrusted semantic proposal. Preserve the deterministic router as the final selector and preserve every existing authority, effect, risk, evidence, context, and ambiguity boundary.

## Contract

The neutral capability contract is `data/compiler-generalization-v2-contract.json`. This is a first-party regression and generalization wave with no third-party source body and no host activation.

## Selection rule

The compiler may carry more than one natural candidate only when:

- each candidate has at least two independently matched provided capabilities;
- each match is exact or a bounded morphological variant sharing a substantial token root;
- every retained card explicitly declares mutual compatibility with every other retained card;
- the retained set does not exceed `maxCompositionSize`;
- existing ambiguity logic has not classified the mission as broad and unresolved.

The compiler does not directly select entrypoints. It emits the capabilities evidenced by the retained cards, then the existing bounded router proves coverage and applies all policy gates.

## Required invariants

- no authority, permission, precondition, or effect comes from prose;
- a generic word such as `review` cannot independently add Forge to an Aegis mission;
- incompatible or weakly evidenced multi-domain language still pauses;
- proposal-assisted composition remains supported but is not required for a clearly evidenced natural composition;
- current arena outcomes and byte determinism remain unchanged unless a new fixture explicitly certifies the changed behavior;
- no host adapter, profile, skill body, or acquired repository code is activated.

## Proof boundary

Local fixtures and a fresh independent host trial can prove deterministic behavior for tested missions. They cannot prove arbitrary language interpretation or authorize execution from a route receipt.
