## architecture

### wave 3 snapshot

a manifest names every exact repository, commit, license signal, and acquisition disposition. a snapshot builder verifies canonical GitHub identity, exact head, clean status, path containment, and every non-Git file digest directly from `D:\03-ARSENAL\warehouse\from-stars`.

the builder emits source records for every `SKILL.md`, exact repository manifests, exact duplicate groups, and one receipt. unreadable or security-blocked files remain explicit failures or rejected evidence. they are never silently omitted from a complete repository claim.

### combined cold corpus

wave 2 and wave 3 source and security ledgers are unioned by exact source id. canonical bodies are selected by SHA-256 across both waves. the combined infusion retains aliases, license signals, security findings, structural metadata, family assignment, and deterministic Godskill target.

the v1 wave-2 artifacts remain immutable. v2 artifacts and receipts live beside them and become the default verified atlas only after all source ids receive exactly one terminal disposition.

### mission skill stack

the existing router chooses a maximum of three compatible Godskills. a new mission-stack compiler binds the request digest, project fingerprint, candidate card digests, route receipt, selected entrypoint digests, uncovered capabilities, authority, effects, risk, evidence level, and context cost into one canonical receipt.

the receipt contains no source bodies and grants no authority. it is the exact compact object a Godagent host may admit into a cortex envelope. changed mission state produces a new digest and a deterministic diff.

### Aegis agentic-ci route

Aegis gains a bounded static-analysis route for GitHub Actions that invoke AI agents. it traces attacker-controlled event material through direct expressions, environment indirection, command-line fetches, logs, outputs, reusable workflows, and evaluation sinks. it separately evaluates sandbox, token permissions, checkout context, allowlists, secrets, and effect authority.

the route reports evidence and mitigations only. it does not execute workflows, exploit targets, mutate GitHub, or treat configuration weakness as an injection path without a source-to-sink trace.

### Hephaestus

`eternities-hephaestus` governs consequential model, runtime, and accelerator selection. it reconciles:

- task and modality;
- quality evidence and benchmark comparability;
- model size, precision, quantization, memory overhead, and context requirements;
- latency, throughput, concurrency, energy, and cost budgets;
- runtime, driver, framework, and hardware compatibility;
- license, data handling, privacy, residency, and deployment constraints;
- local, hosted, edge, and hybrid execution;
- current official evidence and uncertainty.

it refuses false precision, incomparable leaderboard aggregation, memory-fit claims without runtime overhead, stale provider claims, purchases, deployment, credential use, or model downloads without separate authority.

## proof limits

this work proves exact local evidence accounting, deterministic routing and receipts, fixture behavior, and independently written capability contracts. it does not prove every third-party skill is correct or safe, every model benchmark is comparable, arbitrary live-agent judgment, provider availability, hardware performance, legal clearance, or production behavior.
