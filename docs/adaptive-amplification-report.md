# adaptive amplification protocol v1 report

## disposition

adaptive amplification v1 is implemented as an experimental, additive layer.
it does not rewrite the certified Godskills System v3 artifacts, alter the
legacy Godagents adapter path, or promote Muse v4.

the central correction is simple: a capable raw model is the measured floor.
skill routing answers which capability is relevant. activation separately
answers whether that capability should be absent, reduced to hard constraints,
loaded as a full method, or applied in a real later review phase.

## evidence that forced the correction

the reviewed `eternities-oneshots` archive at commit
`265d40d121463de5f3b6215bf513db851ccb8f3b` contains four matched visual
product preferences:

| mission | preferred result |
| --- | --- |
| white fire | raw Terra |
| gravitational portal | raw Terra |
| captive storm | raw Terra |
| bioluminescent ecosystem | Muse v4 candidate |

raw Terra therefore won three of four direct preferences. the Muse candidate
showed useful art-direction, flame-anatomy, and ecosystem-richness strengths,
but also lost preference through reduced spatial inspection, more regularized
secondary motion, and weaker immediate product pull. in the white-fire trial,
the Godskill path used 2.73 times the prompt bytes and 44 percent more wall
time. these observations are bounded development evidence, not a statistically
general model-quality result.

the activation profile records four matched evaluations, one candidate win,
three losses, no critical hard-gate regression, and a 1.44 measured overhead
ratio. it fails the configured win-count, win-rate, and overhead gates. Muse is
therefore not eligible for unconditional `method` activation.

## activation contract

the compiler emits one exact mode for each selected capability:

| mode | pre-inference disclosure | meaning |
| --- | --- | --- |
| `native` | none | preserve raw construction and disclose no selected artifact |
| `guardrail` | contract constraints only | carry hard success, failure, effect, and termination boundaries without method prose |
| `method` | entrypoint and contract | apply the selected workflow before construction |
| `review` | none | preserve a native first attempt and bind a later, real critique phase |

`method` requires an explicit request for the exact method or reviewed,
same-task evidence with at least three matched evaluations, two wins, a win
rate of at least two thirds, zero critical regressions, and overhead no greater
than 1.35. malformed, unreviewed, mismatched, or self-contradictory evidence
fails closed.

the compiler copies the host's authority projection exactly and records
`authorityExpanded: false`. activation cannot create authority, effects,
preconditions, risk tolerance, evidence, context, or composition rights.

## current Muse decisions

the exact experimental receipt resolves the reviewed Muse profile as follows:

| task condition | decision |
| --- | --- |
| creative generation with a real later review phase | `review` |
| consequential creative generation without review | `guardrail` |
| low-consequence creative generation without review | `native` |
| explicit request for the exact full method | `method`, with unchanged authority |

a deferred review descriptor has status `scheduled-not-executed`. neither the
receipt nor the Godagents adapter represents that review as completed.

## implementation boundary

the Godskills repository now contains:

- an exact reviewed evidence registry and neutral contract under
  `artifacts/adaptive-activation`;
- the immutable policy at `policies/adaptive-activation.v1.json`;
- the deterministic compiler at `src/adaptive-activation.mjs`;
- the reproducible builder at
  `scripts/build-adaptive-activation-receipt.mjs`;
- the experimental receipt at `receipts/adaptive-activation-v1.json`;
- focused evidence, compiler, receipt, and installed-host policy tests.

the receipt's internal digest is

its checked file SHA-256 is
`6c6d689ecf9df14823407a917e89a5848776fb50eca3b7acc0d70056ae305f70`.

the Godagents repository adds an optional host-supplied task classifier. its
policy and evidence identities must match the exact v1 trust root, and it can
report only task class, consequence, and real review availability. it cannot
supply a mode. the adapter compiles each decision locally before any selected
artifact read:

- `native` reads no selected artifact;
- `guardrail` reads only the contract;
- `method` reads the contract and entrypoint;
- `review` reads neither and emits only a digest-bound deferred descriptor.

route identity remains present even when artifact disclosure is absent.
activation policy and evidence identities enter source, stack, package, cycle,
and recovery digests. explicit method requests enter the source envelope.
recovery recompiles the stored activation context and rejects a changed policy,
evidence registry, authority projection, decision, or package. omitting the
classifier preserves the certified legacy behavior.

the global Codex skill-routing instructions now apply the same least-intrusive
rule. an installed-host structural test verifies all four modes, the raw floor,
the explicit-method override, creative native search, honest review status, and
authority preservation. this host rule does not activate a default resolver in
every external Godagents runtime.

## verification

focused suites cover all four disclosure modes with real filesystem read spies,
method-evidence thresholds, malformed evidence, authority projection, policy
identity, recovery, and legacy compatibility. the activation receipt rebuilds
byte-for-byte.

the fresh local verification baseline on 2026-08-30 is:

| surface | result |
| --- | --- |
| complete Godskills suite | 632 passed, 0 failed |
| complete Godagents suite | 332 passed, 0 failed |
| installed Codex adaptive-policy structure | 1 passed, 0 failed |
| checked activation receipt | byte-identical rebuild |

one independent Terra review initially found two critical trust-boundary flaws
and three important integration defects: caller-asserted evidence could earn
`method`, a mode-bearing resolver could force a body read, zero-route still
called the resolver, guardrail packages leaked manifest-derived fields, and the
global hard-process exception contradicted the evidence gate. all five were
reproduced and repaired. the same reviewer directly reprobed the corrected
heads, found one remaining manifest-derived termination field, and cleared the
final contract-only repair with no unresolved findings and a ready-to-merge
verdict.

a new creative-mission probe under that single Terra review subject selected
`eternities-muse` but chose `native` and reported zero pre-inference skill-file
reads. this is direct host-routing evidence under a fresh mission, though it is
not a context-pristine second subject and is not a general behavioral proof.

the structural host probe proves instruction presence, not arbitrary future
model behavior. the repository tests prove deterministic compilation and byte
disclosure, not that adaptive mode will improve every unseen artifact.

## proof limits and next gate

this release does not claim statistical significance, universal Godskill
superiority, automatic review execution, Muse v4 promotion, or global runtime
activation. it does not make native mode exempt from ordinary testing,
verification, user requirements, or authority controls.

the next meaningful quality gate is a fresh, blind, matched mission set that
compares adaptive activation against raw execution. it should score direct
product preference, critical regressions, prompt bytes, wall time, spatial
agency, natural irregularity, and task-specific quality. the already-losing
full-injection Muse candidate is retained as development evidence, not used as
the new baseline.
